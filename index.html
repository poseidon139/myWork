REAL-TIME MULTIPLAYER · SPATIAL SYSTEMS

Roam The City

An interactive multiplayer city exploration game where players wander real-world map coordinates in real time. Built to push the boundaries of browser-based concurrency without heavy standalone game engines.

Engineering Insight

When hundreds of players move continuously, a naive global socket room quickly saturates client bandwidth and CPU. I implemented localized spatial grid partitioning using Socket.IO rooms—chunking coordinates into sectors so players only receive broadcast deltas from neighbors in their active viewport, holding latency under 50ms.

STREAMING AI · FACT-CHECKING

PodLens (CiteCast)

A real-time fact-checking companion for podcasts and educational video. While listening, PodLens extracts empirical assertions and verifies them against indexed scientific literature and Google Search Grounding.

Engineering Insight

Running models over continuous audio streams is cost and latency prohibitive. I chunked audio into 30-second sliding buffers on Google Cloud Run, using Gemini 1.5 Flash to filter conversational banter from testable claims. Retrieved citations (PubMed IDs, DOIs) stream back over WebSockets directly onto the video player timeline in under 2 seconds.

GCP Cloud Run Vertex AI Gemini 1.5 Flash Google Search Grounding FastAPI Python React WebSockets

Background & Philosophy

A bit about my journey, what I value when building software, and the technologies I use day-to-day.

I'm a software developer based in Bengaluru with ~3 years of experience building reliable web backends, distributed systems, and practical developer utilities.

I've always been drawn to the plumbing of software—understanding how packets flow over WebSockets, how databases scale under concurrent writes, and how to structure code so it stays easy to reason about months later.
